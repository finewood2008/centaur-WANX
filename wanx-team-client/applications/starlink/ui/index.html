01 / 接口说明v1

从一条有依据的检索开始

在调用方的服务端或主进程保存凭证。将基础地址设为星图服务的 /api/open/v1，并通过 Bearer 认证访问。

当前服务的本机地址连接后读取

若服务运行在盒子上，此地址指向盒子本机。万象应用可沿用 Host 连接，无需暴露服务端口。 

curl "$STARLINK_BASE_URL/search" \
  -H "Authorization: Bearer $STARLINK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query":"项目有哪些关键结论？","limit":5}'
GET/warehouse数据仓概况
GET/documents材料元信息
GET/graph图谱与来源
POST/search可追溯证据检索
GET/evidence/{id}证据位置与摘录
POST/reasoning/…Skill 方法、引用与固定资料读取

以上接口共用同一个 Key。推理资料的八项操作及参数见「推理与调用」。

在万象应用中调用

使用 Host SDK 请求 /api/semantica/open/v1/search，在 X-Xingtu-Key 中传入访问凭证。账号与盒子连接沿用万象，访问范围以凭证为准。 

await host.request("/api/semantica/open/v1/search", {
  method: "POST",
  headers: { "X-Xingtu-Key": token },
  body: { query: "项目有哪些关键结论？", limit: 5 }
});
参数、返回与错误说明

search 接收 query（1–2000 字符）、limit（1–50）、document_ids 与 entity_types。documents 使用 limit（1–200）与 offset 分页；graph 使用 limit（1–500）与可选 entity_id。

检索返回 items，包含 text、document_id、document_version_id、locator 与 channels；图谱返回 nodes 和 edges，每条关系保留 evidence。内容按当前保护规则交付，检测未完成的片段暂缓返回。

401：凭证无效或到期；403：未授权的权限；409：内容变化或尚未就绪。Host 下凭证无效返回 403。接口不提供原件下载、写入、迁移或清空。

独立网页说明：/api/open/v1/docs；OpenAPI：/api/open/v1/openapi.json。

01 / 接入你的应用

先发现方法，再固定材料范围

基础地址与 Key 均沿用“接口开放”。统一知识 Key 同时支持材料信息、图谱、检索和推理资料接口，无需另建推理凭证。旧版 Key 保留原权限，需要完整能力时请新建统一知识 Key。

POST /reasoning/discover
{"arguments":{}}

POST /reasoning/prepare
{"arguments":{"skill_id":"你的方法ID",
 "idempotency_key":"同次重试保持一致",
 "document_ids":["当前仓材料ID"],
 "detect":true}}

Authorization: Bearer <单仓访问凭证>

准备响应返回 preparation_id。之后用它读取引用、在固定范围检索和按页读取正文；方法、材料或权限变化后需重新准备。

/reference
读取方法声明的引用文件
/scope
查看固定的材料版本
/search · /evidence
范围内检索与读取证据
/read-document · /coverage
按页读取正文与查看覆盖

以上均为 POST /reasoning/…，正文为 arguments 对象。接口不允许导入、修改或删除方法。返回内容执行当前仓脱敏规则，不开放原文确认绕过。

detect:true 仅检查当前对象，可能由本仓已确认的在线检测模型处理未经脱敏的文本并产生用量；不会自动扫描全部资料。失败后应明确重试。
