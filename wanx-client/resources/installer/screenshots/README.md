# 安装引导的真实产品截图

三张 PNG 均于 2026-10-20 从当前实际安装的万象客户端采集，连接保持为 CentaurOS-79，没有为截图切换盒子、填造数据或重绘 UI。

- `apps.png`：应用页，精选海报和已安装应用列表。
- `space.png`：空间页，现有「半人马AI学院」资料文件夹，仅展示适合公开的文件名称，没有打开文件内容。
- `box.png`：盒子页，存储、运维工具与关联设备。通过滚动页面让公网 IP 不在截图视口中，没有改写 IP 或监控数字；没有读取到的指标仍保留原来的 `—`。

截图仅裁去原生窗口标题栏与视口边缘，内部文字、按钮、状态、布局没有改写。它们作为 `../posters/` 中生成式营销海报的参考，安装器使用的 BMP / AVI 由海报导出。原始采集文件保留在本机验证目录，不随包分发；`provenance.json` 记录采集来源、裁切范围和源／目标文件校验和。

这些是 **macOS 客户端的真实产品界面**，用于介绍跨平台共用的「应用、空间、盒子」功能；不代表 Windows 安装向导已通过实机验证。以后替换截图时，应从真实客户端重新采集、检查内容可公开性，再更新校验和并生成 BMP，不使用生成式图片模拟产品 UI。
