# WANX 客户端个人资料与积分导航

## 用户入口

主导航为「应用商店」「盒子空间」「我的积分」。积分标签直接显示当前账号的点数，点击查看现有真实余额、任务用量和消耗明细，充值保持不可用。

右上角头像打开账号菜单，包含个人资料、设置和退出登录。个人资料支持昵称、上传头像、恢复默认头像，并显示脱敏的绑定手机号。设置继续提供修改密码、登录电脑时启动和关于万象。

## 本机保存范围

本次按用户选择，以万象平台账号的 accountId 为键，将昵称和头像保存在客户端现有 account.enc 加密存储的 profiles 中。不会调用平台资料接口，不上传头像，不与盒端管理员账号混用，也不跨电脑同步。退出后不展示原账号资料，重新登录同一账号可读取本机已保存内容；不同账号分别保存。

旧账号存储无需迁移或重置。昵称为空时显示「万象用户」。昵称最多 40 个 Unicode 字符，拒绝控制字符；显示时转义。删除客户端本机账号存储会同时移除这些本机资料。

## 头像处理与权限

渲染进程只能请求打开系统文件选择器，不能指定文件路径或通过昵称接口写入头像。主进程读取用户选择的 JPG/PNG，限制为 5 MB，居中裁剪并转换为 256×256 PNG，转换后的内容进入加密账号存储，不保留原路径。

只有管理窗口可执行资料写入和文件选择；快捷面板、远程页面、子框架均无此权限。选择图片期间如退出或切换账号，原操作作废，包括退出后重新登录同一账号的情况。

## 验证

客户端完整测试：767 通过、9 项按条件跳过。新增资料持久化、账号隔离、存储失败、会话切换、输入校验、资料表单保留、菜单导航和 IPC 权限检查。
