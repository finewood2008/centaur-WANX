核心能力

不只是聊天机器人

万象造出来的助手是一个有工作手册的工人，而不是一个提示词包装器。

🤝

AI 产品经理对话

每轮三拍——回读意思 → 写进文档 → 提问。全程只选，不用懂专业术语。

📄

对话即 PRD

右栏实时生成 11 节双语需求文档，边聊边写，可导出 Markdown / 打印成 PDF。

⚙️

确定性编译

同一 AppSpec 永远产出同一应用包——persona 全文、插件清单、技能文件。

▶️

让它跑一次

一个按钮。进度用白话展示，跑完的交付物存进 runs/，随时回看、复制或打印。

📁

给它资料

把会议记录、邮件、随手记粘进去，助手只看你放进来的东西，没有资料就说没有。

🖥️

三个入口

桌面应用（推荐）/ Web 服务 / CLI，同一套逻辑，选你顺手的方式用。

使用流程

四步造出一个助手

从一句需求到一个能干活的 AI 工人，不需要写提示词、不需要懂 API。

1

跟 AI 产品经理聊清楚

描述你想要一个什么助手，它会提问、给选项，帮你把需求写清楚。

2

通读并确认需求文档

11 节双语 PRD 实时生成，确认无误后一键编译成助手。

3

给它资料

把相关材料粘贴进去，助手的工作手册和资料一起落盘。

4

让它跑一次

按下按钮，看进度，拿交付物——每次跑都有存档，随时回看。

快速开始

本地运行只需三步

需要 Node.js 18+ 和 DeepSeek API Key。

# 1. 安装依赖
npm install

# 2. 配置 API Key（也可在应用首屏界面配置）
export DEEPSEEK_API_KEY=你的key

# 3. 启动 Web 服务
WANXIANG_PORT=8788 npm start
# 打开 http://127.0.0.1:8788

开始造你的第一个 AI 助手

克隆仓库，三分钟跑起来；或者直接在桌面应用里双击启动。
