# 万象盒子自动重连

客户端默认恢复当前账号最后中断的盒子连接，不能因掉线切到本机或另一台盒子。重连只恢复连接和授权，不重复发送业务请求。

## 恢复流程

- 已连接时每 30 秒检查盒端 `/api/health`；网络变化、电脑唤醒、网络进程退出与业务连接错误会提前检查。检查串行执行，不叠加多个恢复任务。
- 失败后按 1、2、5、10、30、60 秒退避，之后保持 60 秒重试，不再三次失败就停止。界面保留所选盒子，显示尝试次数、下次重试时间，以及“立即重试”“停止重连”。
- 先尝试当前有效通道；网络进程刚重建、还未同步 peer map 时等待同步，不能反复重建进程打断握手。仅控制面显示 ready 不算恢复，盒端健康检查通过后才恢复使用。
- 同一盒子重新取得授权后，替换网关内部 Agent 与会话，保留 loopback 地址和应用连接句柄。终止旧的在途请求及流，不重放它们；清除旧的应用令牌缓存。
- 盒端令牌自然过期时立即停止使用旧令牌，重新取得授权；网络租约硬过期则销毁旧网络与端点，仅保留账号内的盒子选择意图，在重新读取目录、租约和授权后恢复。明确拒绝授权时停止。
- 主动断开、退出账号、关闭网络、切换盒子和退出程序会取消恢复；过期的异步结果不能恢复旧连接。手动重连也不能使已撤销的跨账号／跨盒子句柄重新有效。

## 数据与任务

空间沿用原有任务、上传 ID、已确认偏移和断点续传流程。主动暂停的任务不会被重连擅自恢复。模型调用、对话、文件写入等非幂等请求失败后返回调用方，不由连接层自动重发；流式会话需要由应用按自身协议恢复。

诊断日志记录 `box.recovery` 的 detected、attempt、waiting、restored，包含允许列表内的错误码、次数、退避时间与恢复耗时，不记录 Token、正文、路径或文件名。

## 2026-10-20 验证

- Node 回归：1,445 项通过，11 项跳过。
- 隔离场景包括：超过三次的持续恢复、退避时间、立即重试、主动停止／退出／关闭网络取消、网络进程重建、自然令牌过期、租约硬过期后重新授权、拒绝授权、旧会话失效、在途写入不重放与日志脱敏。
- macOS 本机实测连接 CentaurOS-79，仅终止客户端自有网络子进程；宿主进程未重启，未点击重新连接。客户端自动拉起网络进程，第二次尝试取得新授权；从检测掉线至恢复约 5.3 秒，从终止进程至恢复约 5.8 秒。
- 恢复后盒子页显示 CentaurOS-79 当前连接，文件空间可读取原有 55 个项目。未更改盒端服务、网络或文件。
- 本机更新以已安装程序为基底，仅叠加重连相关文件，保留上传、文件夹、预览等本地修改及原有原生网络组件；旧程序和加密配置已在本机备份。签名与 ASAR 完整性检查通过。
- Windows 共用逻辑通过隔离测试，Windows 实机断网、系统休眠和跨运营商网络切换尚未验证；本次不声称已查明所有盒端断网原因。
