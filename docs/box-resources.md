# 盒子资源统计

客户端“盒子”页面的 **万象占用** 是当前盒子上的万象文件总量，不是当前账号“空间文件”的大小，也不是整块硬盘的已用容量。

统计范围：

- 当前部署的数据目录 `OCTOP_HOME`，包括所有账号的数据、应用数据、模型、日志、缓存、版本、回收站和部署目录中的备份。
- 当前万象服务的代码、控制台静态资源和专用 Python 虚拟环境；若配置 `PLAYWRIGHT_BROWSERS_PATH`，也包含该浏览器组件目录。
- 部署环境通过 `OCTOP_COMPONENT_ROOTS` 登记的其他万象专有组件与数据目录，使用系统路径分隔符分隔（macOS/Linux 为 `:`，Windows 为 `;`）。例如同机桌面客户端、已安装应用和独立组件的数据目录。该列表由部署管理，客户端请求不能传入路径；不接受磁盘根目录或相对路径。
- 在空间索引中登记的外部存储目录，包括其他账号和 Agent 空间的迁移目录，仅统计万象管理的子目录，不遍历用户选择的整个磁盘。

文件按长度汇总，重叠目录及硬链接按设备号和 inode 去重。不跟随目录内任意符号链接，不将其他软件共用的系统 Python、系统浏览器或远端服务的文件空间算为万象专有组件。计量不等同于文件系统压缩、克隆与稀疏文件的物理块占用。同机但位于部署目录之外的专有组件应登记到上述列表；远端服务应由其管理服务提供计量，不能在本机猜算。

接口仍保留 `/api/personal-space/overview` 的 `filesBytes`（当前用户空间文件）兼容现有应用，另增加 `wanxStorage`（`bytes`、`complete`、`collectedAt`、`scope`）。磁盘扫描在工作线程执行，缓存 30 秒；遇到不可读目录或离线存储，标记不完整，客户端以“≥”及说明展示已读到的下限。旧盒子未返回该字段时显示等待统计，不把个人文件大小冒充总量。

客户端显示 `network.publicIp`，即由**当前盒子服务端**访问固定 HTTPS 回显服务查询到的公网出口地址，界面标为“盒子 IP”（统计口径仍为公网出口地址）。公网查询使用 4.ipw.cn，失败后尝试 [ipify 的 IPv4/IPv6 回显接口](https://www.ipify.org/)。请求不携带万象账号、会话或文件内容；不跟随重定向，校验证书，限制响应长度及等待时间，不使用环境 HTTP 代理。系统级 VPN 或路由策略仍会影响实际出口；该地址也不代表设备允许从公网入站访问。

只接受可公网路由的单播地址，拒绝私网、回环、CGNAT、基准测试网段和无效内容。成功缓存五分钟，查询失败缓存三十秒，`publicIpCollectedAt` 记录查询时间。失败或旧盒子未提供公网字段时显示“暂未获取盒子 IP”，绝不用局域网、容器、万象虚拟网络地址或客户端会话代理地址替代。

`network.addresses` 仍保留服务端启用接口的内部诊断数据及宿主机/容器标识，客户端主卡片不显示这些内部地址。资源接口只提供汇总数值与地址，不返回其他账号的目录、文件名或内容。
