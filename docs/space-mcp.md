# 空间 MCP：每个接入一块专属盘

空间是 WANX 私有云的文件与记忆入口，不按 Agent 品牌分类，也不扫描本机 Agent 日志。

## 使用流程

1. 打开「空间 → 空间 MCP → 接入管理」，命名并创建接入；服务端同时分配 Key 和独立逻辑盘。
2. 复制 MCP 配置到支持远程 Streamable HTTP 和 Bearer 请求头的客户端。
3. 专属盘直接显示在空间侧栏一级入口，与「我的空间」并列。盘内默认有记忆与上下文、对话记录、文件资料、构建物四类目录。
4. 在「记忆归档」复制导入提示词给 Agent。保存目标固定为自身盘的记忆目录，无需另选位置。
5. Agent 调用 `space_access` 核验范围，再用 `space_archive_memory` 保存。真实保存成功后，归档列表展示文件、来源、时间与范围，支持读取实际内容。

每个接入绑定稳定的连接身份、独立 `space_id` 和一级盘根（`parent=""`），不是个人空间内的普通文件夹。同品牌 Agent 可以创建多个接入；复制同一配置、重连、重命名或更换 Key 均复用原盘。目录初始化完成后 Key 才可用；失败重试不重复建盘。

Key 默认可读写自身盘，不可访问其他盘。在「资料授权」另行提供其他文件或目录，默认只读；可单独指定成果回写目录。MCP 不开放删除和移动。撤销额外授权不收回自身盘；暂停或撤销接入停止该 Agent 的全部访问，已保存文件保留。复制 Key、配置由可信主进程完成，完整 Key 不返回页面，服务端仅保存摘要。账号停用后拒绝访问，每次写入提交重新校验。

## 记忆导出的含义

提示词绑定接入自己的盘和记忆目录，要求导出用户授权且 Agent 实际可访问的偏好、项目背景、决定、任务、约束和可见对话摘要。无法访问的历史明确列为缺失。

这不是读取模型内部隐藏状态。系统/开发者提示词、隐藏推理、密码、密钥及登录凭据不进入导出范围。源文件与原始对话不被改写。导出文件标明来源是 Agent 自述，区分事实与推断，保留覆盖范围和缺失说明。

每次归档带稳定的 `operation_id`。失败重试复用该 ID，同一请求不会重复建文件；同一个 ID 携带不同内容时拒绝。归档使用真实的 WANX 文件版本与存储目录。

## 两个独立的盒子端服务

- 空间：`<盒子地址>/mcp/space`，使用空间接入 Key 和目录授权。
- 星图：`<盒子地址>/mcp/starlink`，使用星图仓库 Key，材料、图谱与证据继续受仓库授权约束。

两者由盒子服务端运行，不依赖万象管理客户端保持打开。接入机器必须能通过现有网络连接盒子；本机盒子显示 `127.0.0.1`，不能把这个地址提供给另一台机器。MCP 不自动建立公网隧道。

空间 MCP 采用官方 Python SDK 1.28.1，使用标准 JSON-RPC 和 Streamable HTTP。已用官方 Python SDK、独立官方 JavaScript SDK 1.32.2 与 MCP Inspector 2.12.0 验证兼容；实际协商的是 SDK 支持的协议版本，而不是自定义 HTTP 工具协议。

## MCP 能力

| 类别 | 名称 | 用途 |
|---|---|---|
| Tool | `space_access` | 发现当前 Key 获准的资料与目录 |
| Tool | `space` | 授权范围内的文件元数据、目录、分块读取与版本化写入 |
| Tool | `space_read_text` | 读取 UTF-8 文本、版本与摘要 |
| Tool | `space_write_text` | 幂等新建或版本化更新文本 |
| Tool | `space_archive_memory` | 保存整理好的记忆及真实范围说明 |
| Resource | `wanx-space://access` | 当前授权列表 |
| Resource template | `wanx-space://grants/{grant_id}/files/{entry_id}` | 读取获准文件 |
| Prompt | `import_accessible_memory` | 生成绑定目录的记忆导出提示词 |

团队盘归公司，全体公司成员可查看；所属成员与管理员可管理写入，成员的 Agent 默认只能访问自己的盘。个人盘归当前账号，其他账号及管理员均不能跨账号访问。Agent 权限以 Key 绑定的真实账号为准，不以软件自报名称判断。

通用文件工具复用分片、校验和与文件版本，支持文本、图片和压缩包。默认文本新建到文件资料，构建物显式使用 `workspace.directories.artifacts`。本轮不做图片理解、扫描本机或自动上传产物。现有公开 REST API 地址和格式保持不变，新增的盘管理与客户端文件代理为私有接口。

不保留旧版接入面板、来源侧栏、迁移向导、分享链接流程或桌面本地 MCP 转发；现有空间文件不被删除。
