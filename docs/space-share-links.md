# 万象空间分享链接

文件或文件夹右键选择“提供给 Agent…”，选择只读或成果回写及有效期，生成链接后交给支持 HTTP 的工具使用。目录分享包含其当前及之后新增的子项；单文件分享只允许访问该文件。无需 MCP 配置或万象登录。

## 管理与权限

- 分享由盒端提供服务，客户端关闭后仍按有效期运行。每次访问检查分享状态、创建者当前权限、所属盘和资源范围。
- 只读链接不能写入。成果回写允许新建及版本化更新，不能删除或移动；更新必须提供当前版本，上传提交时再次核验权限。
- 链接绑定稳定资源 ID。同盘移动和重命名保留链接；移出分享目录的子项不再可读。分享根资源进入回收站或跨盘转移后永久失效，恢复或移回不会重新开放原链接。
- 分享使用独立令牌，不复用登录凭据或 MCP Key。响应不缓存、不传递 Referer；盒端访问日志会隐藏令牌。
- 标准空间 MCP 的长期接入、专属盘与资料授权独立管理。

## 撤销与移除记录

“撤销”立即停止后续访问。“移除记录”只适用于已失效的分享，将记录从创建者的分享列表隐藏，不删除原文件。

盒端保留撤销记录和原创建操作 ID。清理可重复请求，但不能通过重试最初的创建操作恢复旧地址。有效链接直接请求移除返回 `409 SPACE_SHARE_ACTIVE`，必须先撤销。其他普通账号及管理员均不能清理不属于自己的分享。

## 接口与兼容边界

现有公开 REST 和空间、星图 MCP 不变。新增私有管理入口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/api/_client/space-shares` | 幂等创建 |
| GET | `/api/_client/space-shares` | 当前账号的未移除记录 |
| GET | `/api/_client/space-shares/{id}` | 详情及链接 |
| DELETE | `/api/_client/space-shares/{id}` | 撤销 |
| POST | `/api/_client/space-shares/{id}/dismiss` | 移除失效记录 |

外部使用 `/space-links/{token}`：GET 提供目录页、`?format=json`、读取与下载；POST 提供分片回写。JSON 描述包含可用操作、块大小及上传说明。旧链接撤销后返回 403；未清理的过期链接返回 410。

支持现有 WANX 账号连接方式。master 的强制设备绑定模式目前没有开放外部分享或对应私有管理路由；本改动不扩展该模式的授权白名单，也不绕过 gateway proof。客户端的旧上下文请求仍会被主进程拒绝，设备身份或会话变化时会清空分享弹窗。

## 回归入口

- `uv run pytest tests/integration/test_space_shares.py tests/integration/test_space_mcp.py -q`
- 在两个客户端目录分别运行 `node --test tests/space-shares.test.mjs`。
- `make all` 及两版完整客户端测试覆盖与 master 的集成；跨仓设备备份夹具需要测试环境提供其外部依赖。

测试只使用临时账号、合成目录和文件，不修改已有用户资料。二进制、安装包、运行目录与测试数据库不属于源码提交。
