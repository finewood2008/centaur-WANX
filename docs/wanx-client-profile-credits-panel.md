# 客户端个人资料、积分入口与快捷面板：分支交付说明

## 交付范围

分支：`codex/client-profile-credits-panel-20261016`。

以 CodeUp `master` 的 `2911404` 为基准，保留主线的客户端/盒端版本更新流程、应用市场与连接权限检查，以及已合入的知君手动启动修复。此分支集中交付三个客户端功能：

1. 右上角头像菜单提供个人资料、设置、退出登录；支持头像上传与昵称编辑，展示脱敏绑定手机号。
2. 「我的积分」成为独立主导航，显示真实可用点数，进入后可查看余额、充值/赠送分类、消耗明细、历史任务与试运行用量。
3. 快捷面板重新设计：静态品牌区、盒子状态与积分卡片、紧凑应用列表、右上角设置、底部应用商店。点击积分卡片进入积分页；Logo 不再触发关于窗口。

主线导航为「应用商店 / 盒子 / 我的积分」。盒子沿用主线现有管理页；设置收进头像菜单，并保留版本更新、修改密码和登录启动等功能。本机并行开发中的文件空间和运维布局可另行合并。

本次没有服务端数据表迁移，没有定价变更、赠送发放或真实支付开关；积分读写权限仍由服务端负责。客户端为只读展示，不恢复已取消的任务报价、预算拦截和追加授权界面。历史预留/退款等已有流水仍可查看。

## 个人资料保存方式

按用户确认的「先按账号在本机保存」实现。资料以万象平台账号 `accountId` 为键，写入现有 `account.enc` 加密存储的 `profiles`，沿用操作系统 `safeStorage` 和串行原子写入。头像和昵称不上传、不跨电脑同步，不与盒端管理员账号混用。

旧存储无需迁移或清空。退出后不显示旧账号资料；重新登录同一账号读取该账号本机资料，切换账号各自独立。资料保存失败时不显示已保存状态；图片选择期间退出、切号或重新登录会取消旧会话的操作。

昵称最多 40 个 Unicode 字符，拒绝空白和控制字符，输出转义。头像支持不超过 5 MB 的 JPG/PNG：只能由主进程的系统文件选择器提供路径，校验实际图片并居中裁剪为 256×256 PNG，再写入加密账号存储。渲染进程不能指定路径、上传任意文件，或通过昵称接口注入头像。

## 积分服务接入

此分支包含客户端的只读传输及 UI；部署端需要已有的兼容账号账本服务。未配置或无法读取时，显示暂不可用/尚未接通，不构造假余额。

推荐通过部署环境设置权威账本服务根地址：

```sh
WANX_CREDITS_URL=https://ledger.example.com
```

地址须为 HTTPS 根地址，不含用户信息、查询或片段；仅开发部署允许 HTTP 回环地址。也可在 Electron 用户数据目录配置 `credits-service.json`：

```json
{"version":1,"serviceURL":"https://ledger.example.com"}
```

配置文件须为普通文件、最大 4 KB；macOS/Linux 须属于当前用户且权限不开放给组或其他用户（建议 `0600`）。环境变量优先。

账号传输携带现有 Consumer 会话及新签名证明，访问 `/api/credits/account/balance`、`transactions`、`reservations/:id`、`tasks` 等只读路径。服务端应验证账号身份与签名，按账号返回账本；余额响应需含与当前账号一致的 `account_id`，以及 `available`、`held`、`paid_available`、`gift_available` 整数。失败、跳转、超大响应、账号变化均拒绝显示。会话过期最多刷新并重试一次。

已有盒端账本可通过 `WANX_CREDITS_DEVICE_ID` 显式固定权威盒子，使用现有受认证的盒端接口。不会把用户随意切换到的盒子当作权威账本。

快捷面板新增固定只读 `panel-balance` IPC，仅返回 `{available}`。主进程验证页面来源，面板没有完整账本、资料写入或扣费接口。首次加载及面板重新获得焦点时刷新，重复读取合并，账号变化立即清空旧余额，晚到结果不串号。真实零余额与加载、失败状态分开显示。

充值入口保持禁用，平台密钥、密码、会话、真实用户资料、数据库和本机配置均不进入本次提交。

## 构建与回退

无需新增依赖，沿用主线锁文件和打包配置；`account/**`、`shell/**`、`local-ui/**` 的现有规则已覆盖新文件。

```sh
npm ci --prefix wanx-client
npm test --prefix wanx-client
npm run start:client
```

回退时恢复本分支引入的客户端代码即可，不需要删除用户存储。旧客户端会忽略 `profiles` 字段；不要为了回退界面删除 `account.enc`，以免清除登录状态和本机资料。
