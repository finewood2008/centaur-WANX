# WANX 桌面客户端 0.1.2：Windows 托盘快捷面板与登录启动

## 解决的问题

Windows 点击系统托盘图标原先直接打开完整管理窗口，缺少 macOS 已有的快捷应用面板。登录时启动设置也只支持打包的 macOS 客户端，本机安装的品牌源码版会被误判为不可用。

## 更新后的行为

- macOS 菜单栏和 Windows 系统托盘均以快捷面板为日常入口：查看盒子状态、连接盒子并打开应用。
- Windows 单击切换面板、双击打开面板；右键打开托盘菜单。点击其他位置收起面板。
- 「设置」和「浏览应用商店」进入完整管理窗口；关闭窗口继续后台运行。
- 面板按任务栏位置定位，支持顶部、底部、左右侧边、多屏负坐标与不同缩放比例；托盘坐标不可用时退回当前显示器工作区。
- macOS 和 Windows 安装版首次启动默认注册登录启动。用户在应用或系统设置中关闭后，后续启动保留选择。
- Windows 注册实际安装的可执行文件和 `--wanx-login-startup` 参数，登录启动时不自动弹出窗口。普通 Electron 调试进程不会注册为登录项。
- macOS 已安装至应用程序目录的万象品牌源码包可设置登录启动；需要系统批准时显示待批准状态，不将其显示为已开启。

## 修改范围

`wanx-client/shell/desktop.mjs` 负责跨平台托盘交互与定位；`shell/main.mjs` 在 Windows 创建快捷面板并初始化默认启动偏好；`shell/startup.mjs` 负责操作系统登录项、首次默认值和用户偏好持久化。对应测试覆盖交互、定位、登录参数和关闭偏好。

客户端包版本及锁文件统一为 0.1.2。未修改盒端服务、账号协议或应用业务数据。

## Windows 发布前验收

1. 使用 Windows 安装包安装并登录，确认任务栏托盘图标正常，单击/双击显示小面板，右键显示菜单。
2. 从面板打开知君；进入设置或商店时才打开管理窗口。关闭管理窗口后托盘与连接继续可用。
3. 在多屏、不同 DPI、任务栏位置及自动隐藏模式下核对面板完整可见，点击外部收起。
4. 确认「登录电脑时启动」默认开启；注销再登录后仅后台运行。
5. 在应用中关闭自启动并重启应用、重新登录系统，确认没有自动重新勾选；在任务管理器禁用后核对状态。
6. 开启 Windows 登录启动后升级覆盖安装，确认启动路径有效且没有重复登录项。
