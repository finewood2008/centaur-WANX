# WANX 盒子资源与 Agent 接入界面更新

交付分支：CodeUp `wanx`，GitHub 同名分支同步相同提交。

## 用户可见变化

### 盒子空间占用

“文件占用”原先仅统计当前账号的空间文件，无法体现万象数据和运行组件的总量。现在盒子页显示 **万象占用**，统计当前部署的数据、应用、模型、日志、缓存、历史版本、回收站、服务代码及专用运行环境，同时计入已登记的外部组件目录和空间迁移目录。

按文件长度汇总，重叠目录与硬链接按设备号及 inode 去重，目录内的任意符号链接不会被跟随。扫描在工作线程执行，缓存 30 秒。目录离线或不可读时以“≥”显示已核实的下限，并提示统计不完整；该值不是整盘已用容量，也不等同于压缩、克隆或稀疏文件实际分配的磁盘块。

### 盒子 IP

界面名称为 **盒子 IP**，含义明确为盒子的**公网出口地址**。由当前连接的盒子服务端查询固定 HTTPS 回显服务，支持公网 IPv4/IPv6，拒绝私网、回环、CGNAT、基准测试网段及无效响应。

请求不附带账号、会话、文件内容或设备身份；校验 TLS、不跟随重定向，并限制等待时间和响应长度。成功结果缓存五分钟，失败后三十秒重试。查询失败或旧服务端未返回公网字段时显示“暂未获取盒子 IP”，不会用局域网、容器、万象虚拟网络或客户端代理地址代替。路由器、系统 VPN 和分流策略会影响查询到的出口，公网出口地址不代表已开放入站访问。

### Agent 接入与访问链接弹窗

Agent 接入、MCP 配置和访问链接共用紧凑的暖白卡片样式：统一无衬线标题、圆角、间距、按钮和空状态。配置内容使用独立等宽代码框，长路径横向滚动，复制与关闭操作对齐在底部。窄窗口继续保持可滚动和可操作。

访问链接列表隐藏目标已删除及已撤销的项目；撤销成功后立即从列表移除。后台记录、撤销状态与审计数据保留。样式针对共享的 `.space-dialog`，也适用于使用该容器的 Agent 工作区接入组件，本提交不另行迁移接入工作流或空间存储模型。

## 接口与部署

`GET /api/personal-space/overview` 增加：

| 字段 | 用途 |
| --- | --- |
| `wanxStorage.bytes` | 当前盒子万象管理文件的汇总大小 |
| `wanxStorage.complete` | 所有登记目录是否均完成统计 |
| `wanxStorage.collectedAt` | 本次磁盘扫描时间 |
| `network.publicIp` | 公网出口地址，失败时为 `null` |
| `network.publicIpCollectedAt` | 公网查询时间 |

保留 `filesBytes` 的当前账号空间含义及原有资源字段，接口协议版本仍为 1。返回值只包含汇总数值与网络信息，不返回其他账号的目录、文件名和内容。

部署时应同时更新盒端服务与桌面客户端。安装在 `OCTOP_HOME` 之外的万象专有组件和数据目录，通过服务进程的 `OCTOP_COMPONENT_ROOTS` 登记，客户端请求不能传入目录：

```sh
# macOS 同机部署示例；按实际安装位置填写。
export OCTOP_COMPONENT_ROOTS="$HOME/Applications/半人马AI-万象.app:$HOME/Library/Application Support/centuarai-wanx-client"
```

Windows 使用 `;` 分隔绝对目录，例如 `C:\WANX\components;D:\WANX\models`。拒绝磁盘根目录和相对路径。外部空间索引中已登记的万象专用子目录自动纳入，不会遍历用户选择的整个磁盘。完整口径见 [盒子资源统计](box-resources.md)。

公网查询需要盒子可访问 `https://4.ipw.cn/` 或 `https://api64.ipify.org/`；无外网时资源页继续提供存储、CPU 和内存数据，IP 显示未获取。既有账号、文件和审计数据无需迁移。回退此提交并重启对应服务即可恢复旧行为。

拉取源码不会自动替换已安装客户端。需按现有打包流程构建、安装后验证；本次分支同步不等于正式安装包发布。
