# 空间存储目录设置（2026-10-17）

用户确认的行为：设置当前空间的文件存储位置，并迁移已有内容。不是把主机已有目录作为文件源接入。

## 使用

在“空间”标签选择“我的空间”或一个 Agent 来源，然后在左下角“存储位置 · 万象主机”点击“设置”。点击“选择文件夹…”：本机万象打开系统文件夹选择器，远程盒子在万象中浏览盒子目录。选定后显示保存位置，再点击“迁移并保存”；“使用默认位置”可迁回默认位置。不再提供路径输入框，取消选择不改变当前选定位置。

指定地址属于当前连接的万象主机，并非客户端电脑。万象在该目录内创建独立的 `.wanx-space/<账号存储标识>/<空间标识>` 子目录；不会读取或覆盖该位置原有的其他文件。文件内容存放于此，索引和授权仍由万象管理。左侧容量显示当前空间用量及实际存储卷容量。

## 迁移与一致性

- 迁移当前内容、上一版本、回收站内容和未完成上传；新写入也使用选定目录。
- 持有文件事务，逐个复制、核对 SHA-256 并落盘，全部成功后才提交位置映射。失败回滚映射并清理本次新副本，保留原内容。
- 提交后再清理旧副本；清理前重新检查当前引用，防止并发迁回时误删正在使用的数据。清理失败会明确提示旧副本尚在，新内容仍可使用。
- 文件 ID、目录关系、摘要、版本和授权不因迁移改变；原访问链接和 MCP 接入继续有效。
- 跨空间复制、移动会把内容保存到目标空间的实际存储位置。缺失或离线目录明确报错，不回退到其他位置。
- 存储设置只开放给可信主窗口的用户操作，不是 Agent 文件工具能力。新接口 `POST /api/personal-space/spaces/{space_id}/storage` 复用当前用户认证。
- 空间很大时迁移需要时间及临时可用容量；客户端超时或断线后应重新打开设置核对当前目录。切换仅在校验完成后发生。异常退出发生在提交后、旧副本清理前时，可能留下旧副本，但不会丢失已提交的文件。
