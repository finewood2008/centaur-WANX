# 万象盒子空间 V1

万象客户端使用“空间”和“盒子”两个独立 tab。“空间”提供文件图标网格；“盒子”集中管理盒子连接、设备发现、网络设置与运维工具。文件空间不是独立应用，此前仅供验收的“网盘实测”独立应用已移除。

文件空间采用类似电脑文件夹的图标网格，支持右键操作、⌘/Ctrl 多选、Shift 连选与空白处框选，可批量下载、移动和移入回收站。拖动已选项目中的任意图标会移动整组项目；目标文件夹、上级路径或侧栏根目录会高亮，松开鼠标后移动。当前目录、已选文件夹自身和无效目标不会接收移动；账号、盒子或连接变化会取消尚未提交的拖动，部分失败时保留未完成项目的选中状态。

支持拖入本地文件到当前文件夹，并显示逐文件进度条、百分比及暂停、继续、取消操作。 主窗口选文件、拖拽及小弹窗拖拽均限制每批最多 20 个文件、单文件最大 200 MB（沿用客户端的二进制口径，即 209,715,200 字节）。恰好达到上限允许上传；任一限制超出时整批不入队，显示具体数量或超大文件名，不静默上传部分文件。主进程在完整批次检查后才创建任务，不影响已有任务的暂停和续传。拖拽文件通过 Electron preload 的 `webUtils.getPathForFile` 转换后进入主进程传输队列，文件路径不返回网页。

## 控制台的命令行入口

客户端页面、菜单、托盘菜单和原 `Cmd/Ctrl+Shift+D` 快捷键不再提供控制台入口，旧的 `dashboard-open` 管理 IPC 明确拒绝请求。终端、远程桌面继续通过独立运维窗口访问当前盒子。

在当前 Mac 的 terminal 中运行以下命令打开控制台：

```sh
/usr/bin/open -na '/Users/finewood/Applications/半人马AI-万象.app' --args --wanx-console
```

其他安装位置使用对应应用路径；Windows 使用已安装的客户端可执行文件加 `--wanx-console`。该参数交给拥有同一用户数据目录的现有万象进程处理，只打开当前已登录、已连接盒子的控制台；冷启动时等待原有连接恢复。参数不接受盒端地址、用户 ID 或令牌。

客户端的“空间”页使用当前连接盒子的本地磁盘存储当前用户的文件。提供目录浏览、上传、下载、重命名与移动、回收站、恢复和永久删除。传输使用 4 MiB 分块和 SHA-256 校验，上传任务可恢复；客户端任务记录通过系统安全存储加密保存。

## 应用访问约定

第一版不做逐应用、逐文件或文件夹授权。同一用户的万象应用直接共享该用户的盒子空间，应用通过有效 Host 会话调用 `host.drive`。用户切换盒子、退出账号或会话失效时，原会话撤销。服务端仍校验用户身份、产品可登录状态和文件归属，不同用户不能通过文件 ID 互相读取。

Host SDK 版本为 `@centaurai/wanx-host-sdk@0.3.0`，用法和类型见 `wanx-client/host-sdk/README.md` 与 `drive.d.ts`。应用可使用 `list/stat/mkdir/move/trash/restore/purge/upload/read`。旧应用接入时需要使用新 SDK 或对应 HTTP 接口。

## 存储与接口

- 接口前缀：`/api/personal-space`。
- 存储位置：盒端运行数据根目录下的 `.wanx-personal-space/<user-id>/`，使用独立 SQLite 文件索引和不透明文件对象。
- 原有 workspace 与后端文件接口阻止直接访问这块私有存储，文件通过盒子空间接口按当前用户访问。
- 存储容量显示实际所在磁盘的容量和余量；第一版没有给每个用户另设容量配额。
- 文件同名时自动保留两个名称，删除先进入回收站。

## 快捷面板与构建

整个快捷面板支持多文件拖入，固定保存到当前盒子的根目录；拖入时显示遮罩，上传中显示进度及暂停、继续操作，完成后隐藏传输区域。切换到访达时保持展开，按 Esc、再次点击菜单栏图标或打开应用时收起，后台上传继续。应用入口位于“我的应用”标题右侧，底部为紧凑的空间入口、目标位置、就绪状态和拖入提示。

终端与远程桌面的独立页面源代码位于 `dashboard/src/maintenance/`。运行 `npm --prefix dashboard run build:maintenance` 可重建客户端工具资源；开发启动与客户端打包也会执行构建，构建产物不纳入 Git。

2026-10-17，用户确认当前空间和小弹窗功能无问题，并要求分组提交代码。本轮通过代码与自动检查确认提交范围，没有继续操作窗口；此前未完成的原生拖放复测不补记为工具实测通过。

### 文件名称与预览

- 本地选择上传使用原文件名；拖拽上传同时携带 File.name，避免操作系统临时路径的文件名替代用户看到的名称。保留中文、组合字符、内部空格和 emoji，不做编码转换或 Unicode 归一化。同目录同名仍沿用编号避让，不覆盖原文件。
- 文件名不符合盒端规则（首尾空格、路径字符、结尾点或超过 240 个 UTF-8 字节）时整批拒绝，避免盒端静默修改名称。
- 文件区可切换“预览模式”：PNG、JPEG、GIF、WebP 图片按可见范围串行加载缩略图，最多读取 16 MiB 原图。缩略图只驻留内存，切换账号或盒子即清空；上传忙碌时暂停发起缩略图请求。
- 双击可预览图片、PDF 与文本，弹窗提供下载原文件。其他格式、超限或读取失败时给出提示，仍可下载。关闭预览后到达的响应不会重新弹出窗口。
