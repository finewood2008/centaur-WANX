# 万象菜单栏 UI 重设计验收记录

日期：2026-10-13。基于 CodeUp master `a358355451ce1170d0dae86e97cb8e5a6ed14134`，工作分支 `codex/wanx-menu-bar-20261013`。按用户要求提交独立分支，master 不合并。

## 实现

- 品牌为“半人马AI-万象 / CentaurAI-WanX”，窗口及快捷面板的 Logo 可打开“关于万象”。按最后确认的要求，macOS 菜单栏使用半人马单色模板及 Retina 资源，窗口内保留橙蓝原图；宿主隐藏 Dock，具体应用保持独立窗口与 Dock。应用身份与账号存储不变。
- 400 像素快捷面板，最高 560 像素；紧凑应用列表、被动显示盒子状态、打开就绪后收起、Escape/失焦收起。仅在未连接而请求打开应用时出现确认盒子的选项。
- 单一 860×640 可调整管理窗口：应用商店、设置。低频的管理与切换盒子放入设置，盒子列表有返回设置入口。关闭隐藏；蓝牙配网仍由管理窗口持有，登录与 Wi-Fi 输入在后台状态更新后保留。
- 显式“连接盒子并打开应用”、按账号和服务环境保存上次成功设备预选；取消、切盒、退出登录、同账号重新登录均使旧意图失效。
- 主进程广播两窗的连接、安装清单与按应用区分的操作状态；旧异步读取不能覆盖新结果，后台安装不锁住其他应用。
- 精确校验两个窗口各自的 webContents、主 frame 与本地 URL。快捷面板不开放登录、安装、卸载、版本选择、手动连接/断开/刷新盒子或蓝牙 IPC；开放无账号和网络变更的关于弹窗。
- 登录项仅在打包 Mac 中按用户操作写入，随后读取系统真实结果；开发预览不登记，登录项启动保持静默。显式退出说明应用和连接将关闭，并等待原有清理流程。
- 设置中的“退出当前账号”结束账号会话并断开盒子，宿主继续运行；完全退出仅放在系统应用菜单和托盘右键菜单，保留已有退出确认及应用清理流程。
- 发现列表读取同一蓝牙外设的公开设备身份，按完整 ID 匹配账号中的盒子名称；其次使用盒端非通用名称。名称不可得时明确显示“未获取到盒子名称”，完整 ID 与广播名只作核对信息，不能冒充名称。助手仅只读固定公开特征，不配置网络或认领。显示提示不进入配网授权输入。
- 未登记或配对窗口已关闭的公开预览禁止继续配网，界面说明原因，宿主在安全握手前再次检查。配网失败使用专门的错误文案。

## 已完成的验证

- 客户端最终回归共 464 项：459 通过、1 失败、4 个需要专门环境的测试跳过。相关 UI、名称匹配、配网前置检查、账号切换、取消迟到连接、按应用并发、双窗竞态、受限 IPC、Windows 托盘行为和模拟多屏定位均通过；最后一次相关界面与交互定向检查为 101/101 通过。失败是未改动的 `host-http-seam.test.mjs` 超大上传测试：HTTP 拒绝响应与写入关闭竞争，偶发先得到 EPIPE，预期为 HOST_REQUEST_TOO_LARGE；该文件独立重跑曾通过，最终全量仍复现。本次不改无关上传实现，不将回归报告为全绿。
- 名称助手 arm64 编译、构建缓存、plist 检查与 18 项 Swift 解析边界检查通过。实际 Mac 初次扫描发现 8 台候选，7 台读取到完整盒子 ID、1 台读取失败；当时账号设备目录为空，因此没有可验证的自定义名称，不能把读到 ID 当作名称验收。此后账号目录出现 8 台命名盒子，但尚未重新完成真实扫描的逐一名称匹配验收；完整 ID 精确匹配与 ID/广播代码不冒充名称由回归测试覆盖。
- 对用户配网失败的 664CEE 盒子仅只读固定 Device Info，确认 protocol_version=2、cloud_enrollment_status=not_enrolled、network_state=unprovisioned、pairing_mode_remaining_seconds=0。盒端当前未登记且配对窗口关闭，不具备继续配网条件。未写入 Wi-Fi、未认领、未修改盒子状态。主进程新增握手前拒绝检查并通过测试；完整实机配网仍未验收。
- 重新构建管理窗口配网脚本；最终 Mac arm64 本机应用包构建成功，确认包含名称读取助手，并重新通过打包应用 manifest 启动隔离测试。
- 实际 Mac 窗口检查：快捷面板外观与自适应高度，开发预览开机启动为关闭且不可选；关闭管理窗口保留运行，Escape 收起面板。正常退出弹窗显示关闭所承载应用和断开连接的说明，确认后退出并能重新启动。最新设置页已通过仅刷新渲染界面的方式验收：仅应用商店/设置两项导航，设置内显示“管理与切换盒子”和“退出当前账号”；窗口内完整中英文品牌文字也已刷新，并实测点击 Logo 打开系统关于弹窗；CentuarAI-AMD-102 连接保持正常，没有关闭已打开的应用。旧实例的关于弹窗仍使用启动时的旧品牌信息。
