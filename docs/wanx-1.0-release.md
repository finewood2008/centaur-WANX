# 万象 1.0：一个后端，两个客户端

版本：**1.0.0**。整合分支：`wanx1.0`。本次基于 CodeUp `master` 的 `c443e73755dc2dc6967e53ba347816a4d96ec3fb` 整合 2026 年 10 月 22–23 日的本地开发。

## 产品与代码边界

| 产品 | 代码 | 身份与数据 |
| --- | --- | --- |
| 万象个人版 · CentaurAI-WanX Mini | `wanx-client/` | 保留原客户端身份、账号配置和个人数据目录 |
| 万象团队版 · CentaurAI-WanX Studio | `wanx-team-client/` | 独立安装身份、窗口、配置目录和 `stable-studio` 更新渠道 |

| Builder 组件 | `wanx-studio/` | 团队管理员使用；服务挂到同一 WANX 进程，沿用真实操作人 |

1.0.0 是 WANX 产品与两个客户端的版本号。底层 `octop` Python 包保留上游独立组件版本，避免把 `1.0.2b4` 降级为 `1.0.0`。

## 两天开发的功能梳理

### 个人版

- 保留现有客户端框架和盒子连接栈，品牌为 CentaurAI-WanX Mini。
- 内置 AI 对话、历史会话、新会话切换、按账号与盒子保存模型显示配置。纳入最新 master 已合并的对话更新。
- 通知中心与个人入口；积分位于个人菜单，不占主导航。
- macOS 使用当前已采用的本地加密凭据保存方式，保留旧凭据的受控迁移，不把凭据带进安装包或仓库。

### 团队版

- 同一盒子可由多个真实账号登录。管理员管理构建、星图、成员与上架；普通用户使用获准应用、AI 对话、空间和盒子。
- 应用页为“万象应用／公司应用”两个 Tab。管理员验收并内部上架后，获准成员使用自己的身份运行应用。
- 星图首页突出真实知识图谱、数据仓与材料处理概况；支持导入、证据检索、任务和失败重试。
- 复杂知识操作交给星图软件；携带团队、仓库与页面定位，校验当前账号和盒子，连接变化时拒绝旧结果。
- 仓库页面生成绑定该仓的 Key，星图 MCP 与空间 MCP 保持独立；地址置于页面底部。凭据不进入构建源码或应用发布包。
- 通知中心、积分与品牌位置沿用个人版，团队版独立保留账号配置。

### Builder 与简化构建流程

1. 客户端输入需求，按需点击 AI 补全；补全可编辑，经确认才作为任务简报。
2. 手动选择星图数据仓、指定的万象空间目录、参考资料与 ACP 构建器。
3. 进入 Builder 后阅读获准材料，沟通并完善七部分 PRD。疑似含凭据的材料明确阻止，不发送给模型。
4. 核对并确认方案后，由 Codex 经 ACP 完成受控开发；展示过程、源码变化和校验结果。
5. 亲自试用、记录改进、采用版本；保留版本历史、业务数据和历史基线。构建并不等同于采用或上架。
6. 成功版本按选定空间目录归档；使用完整受信产物，归档失败显示状态并可重试。

本次修复了需求确认后新增能力导致的额外手动检查断点，以及归档误读公开摘要、缺少源码的问题。已知能力采用真实隔离探测，失败或未接入能力仍阻断开发。

## 源码构建

服务器从同一仓库启动：

```sh
uv sync --frozen
npm --prefix wanx-studio ci
octop run
```

从仓库运行时自动定位 `wanx-studio/`。仅安装 Python wheel 的部署，另行安装同版本 Builder 源码与 Node 依赖，并设置 `WANX_STUDIO_ROOT=/path/to/wanx-studio`。Builder 需要 Node.js、已配置的模型和可用 ACP 引擎。它不会复制用户模型配置或另建团队服务器。

客户端：

```sh
npm --prefix wanx-client ci
npm --prefix wanx-team-client ci
npm run start:mini
npm run start:studio
```

团队版启动或打包前从 `wanx-studio/` 源码生成工作台、受信桥与星图模块。生成文件不提交。正式签名、公证和更新发布仍走客户端已有发布工具；此分支提交本身不会发布安装包或生产标签。

## 数据与兼容

- 既有公开 API 地址和请求、响应格式保持兼容；新流程使用私有客户端路由和 IPC。
- 数据仓共享以团队边界隔离；个人仓不自动迁移。普通用户访问同时受应用范围、仓库授权和保护规则约束。
- 两个客户端独立安装与更新，共用盒子服务，不复制另一客户端的账号或运行数据。
- 提交仅含源码、必要静态资源、锁文件、测试与说明。排除安装包、ASAR、编译目录、视频、日志、数据库、模型配置、仓库材料、Key、账号与试用数据。
