## 使用与边界

- 在“空间 → 来源 → 接入 → 生成新的 MCP 配置”生成每个用途的配置。配置文件路径代表一个持久身份；复制同一配置共享空间，不按软件自报名称分配身份。
- Agent 首次申请后，在“接入”中确认来源名称。确认前只能查询状态。工具默认读写自己的空间；`space_access` 返回空间及额外授权，额外授权操作显式携带 `grant_id`。
- 右键文件或文件夹可授予指定身份额外读写权限；空间管理中单独撤销。Agent 不支持跨授权范围移动。
- 用户可跨空间复制、移动；移动前显示来源、目标和授权变化。跨空间移动会撤销以被移动资源为根的旧链接及额外授权，移回也不会自动恢复。
- 暂停阻止新操作及未完成写入提交；断开撤销凭证与额外授权，文件保留。回收空间同步断开；恢复仅恢复文件，需要用户再次确认接入。
- 旧文件归入“我的空间”，保留资源 ID、层级、内容与版本。旧链接保留原范围；旧接口默认个人空间。应用默认目录按需创建，不迁移旧应用文件。
- 常用位置只在本客户端按平台、账号、盒子保存。小弹窗仍上传到“我的空间”根目录。
- 本机服务只监听回环地址，保留 Host/Origin 检查。凭证不放入本记录；MCP 不限制 Agent 在电脑上使用其他工具。

## 安装版与本机盒子实测

安装版客户端和当前本机盒端已更新，保留现有用户数据和运行时其他改动。部署前保存逐文件备份与清单；客户端签名验证通过。

实际验收使用两个独立安装版 stdio MCP 进程和两个新配置，在界面分别确认接入：

1. 两个申请审批前均拒绝文件操作；审批后创建不同空间。
2. 各写入一份 40 字节样本，读回正文并核对 SHA-256；彼此默认不可访问。
3. 额外授权后允许读取，撤销后立即拒绝；界面暂停 A 后 MCP 拒绝操作，恢复后可继续。
4. 三级目录树、当前位置、前进、后退在安装版通过。
5. 多选文件和文件夹拖到另一个空间，出现明确确认；确认后两项均移动。原身份对移走文件失去访问，目标身份可访问。
6. 文件拖进目录，再拖到面包屑上级根目录，均在目标目录核对到文件。
7. 右键固定目录到常用位置，拖文件到该位置，进入后核对成功；测试固定项随后取消。
8. 安装版连续英文逐字输入、选区替换、中间插入和 Enter 保存通过。系统中文输入法切换没有得到可靠确认；Chromium 组合输入自动测试已通过，但不能替代系统中文输入法人工验收。
9. 重启安装版后，端口不变，原两个 MCP 身份继续访问原空间，没有重复创建。启动连接尚未恢复时返回不可用，连接恢复后通过。
