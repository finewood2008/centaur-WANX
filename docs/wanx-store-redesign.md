# 万象应用商店界面改版（本机开发版本）

应用商店参考 [Apple Mac App Store Discover](https://developer.apple.com/app-store/discoverability/) 的推荐与应用信息层次，保留万象暖白、铜色品牌和账号／积分导航。

## 首页推荐栏

采用横向海报卡片，每页固定两款应用，共两页：

1. 知君、半人马环。
2. 众见、万象 AI 浏览器。

海报完整保留 3:2 比例，每张下方显示应用图标、名称、一句介绍和查看入口。移除原先通栏单张大海报、模糊填充背景与图左文右条幅。卡片宽度随窗口适配，横向滚动使用原生滚动与整页吸附。

每 5 秒切换一页，第二页结束返回第一页。支持触控板／触摸横滑、左右箭头、两页圆点和暂停／继续。鼠标悬停、键盘焦点进入或窗口内容隐藏时暂停；系统减少动态效果时默认暂停。轮播只更新展示位置，后台状态轮询不会重建正在操作的控件。

四款官方推荐可查看产品介绍；未安装或市场未提供的应用不会凭宣传卡获得安装／打开权限，也不会计入“我的应用”。

## 应用卡片与产品介绍

下方是自适应“我的应用”和“发现应用”网格。打开、安装、更新、回退与卸载使用原有受信任 IPC 和确认流程。六款应用各有独立介绍页，显示分类、版本、实际安装状态、功能介绍和可放大的产品海报；版本说明与管理操作继续保留。

生成图标位于 `wanx-client/local-ui/renderer/assets/app-icons/`，海报位于 `assets/posters/`。海报是宣传概念图，不充当产品截图；完整提示词见 `wanx-app-icons-prompts.json` 和 `wanx-app-posters-prompts.json`。后续上架素材要求见 [应用上架素材规范](wanx-marketplace-submission-assets.md)。

本次只更新客户端商店展示，不涉及支付、预算或模型服务。

- 本机 macOS 客户端重启后，已观察第一页知君／半人马环并排展示，点击下一页后完整显示众见／万象 AI 浏览器，页码同步为 2 / 2；Windows 未做实机验收。
