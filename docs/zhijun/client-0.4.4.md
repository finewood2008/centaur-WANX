# 知君 0.4.4 配套后端

本分支在万象 `b2aae47` 基础上合入知君客户端已验证的本体与微信补丁，保留该基线的启动超时、工作区兼容与工具名称修复。

## 同步范围

- 私有角色独立整理本体候选；未经本人确认的候选不自动成为本体。
- 对话中的明确本人声明可直接确认纳入，保留来源、角色、确认记录及撤回后的状态。
- 微信绑定由服务端 QR 会话核验本人；禁止浏览器自行填写绑定身份、禁止跨角色复用同一微信机器人绑定。
- 微信消息、抢占命令和主动推送均校验当前角色及扫码本人；群聊和其他发送者被拦截。
- 知君客户端的主动联系程度沿用万象现有 `proactive-care` 接口及调度，本补丁不修改用户已有联系频率。

## 部署边界

推送源码不会自动更新服务器。先备份现有配置和数据库，在独立环境完成依赖安装、构建及验证后，按原有部署方式更新并重启万象。此更新不包含用户数据、凭证或数据库迁移，也不改变已有角色归属。

本分支已经包含后端补丁，不要再将 `newzhijun/backend-overlay` 中针对旧运行时的完整文件直接覆盖到本分支。旧环境补丁安装器有版本与哈希检查；遇到版本不同应合并升级，不能跳过检查。

旧微信连接若尚未核验扫码本人，需要在对应角色的“设置中心 → 微信连接”重新扫码。Windows 安装包本身不会更新万象服务。

## 验证

新增回归测试位于 `tests/unit/api/test_zhijun_ontology_flow.py` 与 `test_zhijun_wechat_owner.py`，覆盖确认幂等、角色隔离、来源撤回、绑定归属和非本人拦截。它们使用临时数据与模拟微信接口，不向真实微信发送消息。
