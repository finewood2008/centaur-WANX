## 用户可见变化

1. 主导航、页面标题、返回入口和积分提示统一使用“应用”“积分”；头像菜单继续提供个人资料与设置。
2. 快捷面板右上角从齿轮“设置”改为盒子图标及“盒子”，通过既有 `desktop-open { page: "boxes" }` 打开管理窗口的盒子板块。只进入管理页面，不连接设备或启动应用。
3. 普通管理页共用最大 1180px 的内容容器，常规页边距为上／左右 30px、下 32px；小窗口使用原有公共断点。页面标题与应用页统一为 29px 无衬线，窄屏为 25px。根页面预留滚动条空间，减少切换标签时的水平位移。
4. “我的应用”和“发现应用”的卡片，点击图标、名称、介绍及空白区域均可进入详情。沿用现有详情按钮的点击语义及键盘入口，并增加整卡焦点轮廓。打开、安装、更新、版本选择和版本管理区域保持独立操作；展开的管理内容不会误触详情跳转。
5. 内置六款官方应用的介绍可持续在“发现应用”找到。卸载后只从“我的应用”移除；重新启动客户端后仍可查看其介绍和海报。远端目录优先、按应用 ID 去重，安装数量继续来自实际宿主状态。
6. 是否显示安装按钮仍取决于账号市场返回的可安装候选版本。未提供安装包的应用显示“暂未提供可安装版本”；保留介绍不等于上架或具备重新安装权限。没有补造安装包，也不会自动重装已卸载的应用。

- 本分支基线主导航为“应用／盒子／积分”。本机另外开发的独立“空间”页、存储和负载指标、拖拽上传、星图接入不在本轮增量中。合并到已包含这些功能的分支时，保留其路由和入口，不应整文件覆盖 renderer.js 或 panel.js。
