# 本机万象作为盒子

桌面端在启动和「我的盒子 → 刷新」时，同时读取平台设备目录和当前操作系统用户的本机服务登记。已完成初始化且健康检查通过的服务以「本机万象」显示，可直接连接和打开管理界面。连接使用回环地址，不依赖 NetBird 或远程盒子的在线状态。

这项能力只发现同一台电脑上明确登记的服务，不提供局域网广播，也不会把本机服务自动登记为云平台设备。

## 登记格式

登记目录：`~/.wanx/local-boxes/`。Windows 使用当前用户主目录下的同名目录。每台本机盒子使用持久化的 `local-` 加 24 位小写十六进制 ID；更换端口不改变 ID。

文件名必须为 `<deviceId>.json`，内容为：

```json
{
  "version": 1,
  "deviceId": "local-0123456789abcdef01234567",
  "displayName": "本机万象",
  "serviceUrl": "http://127.0.0.1:8089",
  "username": "本机服务管理员账号",
  "password": "本机服务管理员密码"
}
```

文件包含登录凭据，应由本机初始化工具或部署人员写入，不能提交仓库或放入应用安装包。macOS/Linux 文件必须属于当前用户、权限为 `0600`，建议目录为 `0700`；不接受符号链接。Windows 应保存到当前用户私有目录并使用用户级 ACL。只接受 `127.0.0.1` 或 `[::1]` 的 HTTP(S) 根地址，不接受远程地址、URL 内凭据、查询参数或片段。

## 连接与失效

- `/api/health` 返回健康且数据库已绑定后，盒子显示可连接；服务停止时保留离线卡片。
- 桌面主进程通过 `/api/auth/login` 验证本机账号，使用已有的受限本地网关打开管理界面。密码和真实 JWT 不进入页面、IPC 状态或设备列表。
- 本机认证成功的连接标记为 `local`；普通开发用 `direct` 连接不获得盒子权限。
- 应用仍使用现有 Host 接口；需要应用范围令牌时，通过本机 `/api/auth/application/exchange` 执行服务端权限检查。
- JWT 到期前续期；每 30 秒检查服务和登记是否仍有效。退出账号、切换账号或盒子时关闭会话。删除登记后刷新可立即断开，后台检查最多约 30 秒加探测超时后断开。
- 云网络关闭不影响已经建立的本机连接。本机服务关闭、登录失败或初始化未完成，不会显示为已连接。

这里的本机管理员身份不等于 WANX 云账号身份，不会自动绑定云积分账户、配置模型或启用云端扣费。

## 验证

运行 `cd wanx-client && npm test`。相关用例覆盖登记校验、敏感字段隔离、真实 HTTP 登录及网关、应用范围交换、错误凭据、服务停止、取消连接、云网络关闭时的本机连接，以及应用/管理界面的连接门禁。
