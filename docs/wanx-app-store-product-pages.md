# 万象应用商店：六款应用图标与产品介绍页

日期：2026-10-16。范围：知君、个人议事厅、众见、半人马环、万象 AI 浏览器、视频号助手。

## 页面与入口

- 使用 image_gen 分别生成六款应用图标，共用柔和材质与圆角比例，各自保留颜色和符号。原始生成图仍保留，项目副本位于 `wanx-client/local-ui/renderer/assets/app-icons/`，完整提示词见 `wanx-app-icons-prompts.json`。
- 商店卡片的图标、名称与“了解应用”，以及精选推荐入口，都进入独立的应用介绍视图。它使用本地页面状态，不修改宿主受信任的 URL，也不因查看介绍启动应用或安装软件。
- 每页包括分类、当前真实版本、安装状态、打开／安装／更新操作、可放大的产品介绍海报、产品介绍、三个功能亮点、版本说明与管理操作。没有虚构评分、下载量或评价。
- 快捷面板复用同一份图标映射。后续应用没有编辑资料时，继续使用市场／宿主提供的图标和介绍。
- 购买、支付、预算、账号资料存储与应用后端均不属于本次变更。

## 当前海报与素材交付

按用户要求，移除此前八张产品界面截图及客户端引用，六款应用各提供一张独立的 3:2 产品介绍主海报，位于 `wanx-client/local-ui/renderer/assets/posters/`。海报使用各自图标作为品牌参考，通过 image_gen 生成，覆盖产品名、价值主张、三个核心功能与独立主视觉；提示词见 `wanx-app-posters-prompts.json`。

| 应用 | 主海报 |
| --- | --- |
| 知君 | 有处可说，有迹可循。 |
| 个人议事厅 | 一起商量，由你决定。 |
| 众见 | 一个问题，多种智能视角。 |
| 半人马环 | 人在环中，AI 持续行动。 |
| 万象 AI 浏览器 | 这一页，和 AI 一起完成。 |
| 视频号助手 | 从一段视频，到从容发布。 |

海报属于宣传概念图，不包含模拟界面，不代表应用实机验收。原本的截图已备份到项目外的本机 runtime 备份目录，不再随客户端分发。

后续每个应用提交上架安装包时，必须同时交付图标、Logo、3–8 张真实产品截图、1–3 张产品海报、文案与素材索引，详见 [应用上架素材规范](wanx-marketplace-submission-assets.md)。真实截图由应用提交方提供并负责版本一致、合法授权和脱敏，海报不能代替截图。该规范目前为交付与人工审核规则，打包器／Admin 还没有自动校验和导入索引。

## 首页推荐栏（2026-10-16 更新）

首页使用两页横向海报卡片，第一页为知君与半人马环，第二页为众见与万象 AI 浏览器。每页两款，图标与一句介绍位于各自完整海报下方。每 5 秒自动翻页，支持手动横滑、左右箭头、两页指示点与暂停；查看介绍不隐式安装或启动应用。相关轮播与渲染回归 137 项通过。详细行为见 [商店界面改版说明](wanx-store-redesign.md)。
