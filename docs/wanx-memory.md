# 万象记忆模块

当前产品边界（2026-09-30）：万象提供原生记忆模块及其 API；知君作为独立应用，在自己的应用层使用万象 API。

## 页面与源码

- 侧栏「记忆」是独立入口，紧接「个性化」，地址为 `/memory`。旧地址 `/personalization/memory` 重定向到此处。
- 原有概览、用户画像、记忆库、情绪日记、沉淀、整理记录、对话记录、主动关心和设置恢复原有实现。恢复基线为品牌适配完成、个人本体改造之前的 `e889304`。
- 原生 `dashboard/src/pages/Agent/Memory/` 下既有生产源文件与该基线一致；独立路由页面 `index.tsx` 是外层入口。
- 新功能仅为「用户画像」中的内容点阵雷达。四类区域沿用关于你、当前重点、你提到的事实、关键人事物。每个点对应原有画像摘要中的一条内容。
- 点的位置只用于排布，不表示分数、可信度、确认程度或人格强弱。不生成新结论，也不加入本人校准流程。
- 每类读取最多 12 条，与原生画像摘要窗口一致。图中不是整个记忆库的数量统计。点击内容可通过原有入口进入记忆库查看和修改。

扩展代码位于 `dashboard/src/extensions/memory/`。`dashboard/memoryProfileExtension.ts` 只重定向 `MemoryPanel.tsx` 对 `./ProfileOverview` 的导入，组合雷达与原生画像组件。Vite 和 Vitest 使用同一插件；原组件自身及其他模块源码无需插入扩展调用。上游重命名文件或导入路径时，需要检查该插件及集成测试。

## 数据与接口

可视化使用 `memoryDashboardApi` 已有的 `terminalAboutMe`、`terminalCurrentFocus`、`terminalThingsYouToldMe`、`terminalEntities` 四个查询。鉴权、专家作用域、画像生成、沉淀和记忆修改均由原生模块负责，没有增加接口或数据库结构。

图与原生画像各自读取相同摘要接口；刷新雷达只刷新其摘要窗口。记忆库原有编辑与删除操作保持原样。不同专家切换时取消旧请求的显示结果，防止旧专家结果覆盖当前专家。

## 旧个人本体的退出

按用户明确选择，完全恢复原生记忆调用：

- 不再挂载 `SelfModelMiddleware`，原生自动记忆注入、检索工具与团队调用恢复原配置。
- 不再注册 `/api/agents/{agent_id}/memory/self-model/*`，OpenAPI 不再展示该接口组。
- 不再提供旧本体全景、确认、校准、反思对话等界面。
- 既有迁移、数据库表、记录和离线服务代码保留为历史存档；不做删除、转换或再次提炼。旧设置即使为 enabled，也不介入现在的助手运行。

旧本体的拒绝或撤回记录不再过滤原生记忆；若原记忆库仍保留同一内容，原生流程可以再次使用它。这是用户已确认的恢复边界。当前记忆内容的修改以原生记忆库为准。

知君后续作为独立 API 消费方设计自己的本体、校准与应用交互。本次不创建知君应用，也不将其规则嵌入万象记忆模块。
