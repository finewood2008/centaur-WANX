# WANX Mini：AI 对话

客户端标准导航为「应用 / AI对话 / 空间 / 盒子」。AI 对话复用众见账号、模型目录、历史及逐轮用量记录，在客户端主界面内直接渲染，不启动独立窗口。原众见应用及托盘入口转到该 Tab；安装包和原始数据不删除。

## 使用方式

- 默认模型列表仅纳入云端模型；本地模型按后台 `is_local` 标识排除，旧盒子兼容明确的本地标签。原本地模型配置、历史和其他应用保持可用。
- 每轮只使用一个模型。切换到不同模型立即开启新对话，不携带旧会话 ID 或回答上下文；输入草稿保留，真正发送时才创建新的服务端会话。图标只来自本仓库已有素材；模型列表以当前盒子实际返回的配置为准。
- 原对话保留在历史中，点击当前模型不会清空对话。同一模型续聊继续原会话与所选回答的祖先上下文，历史回答保留模型署名；不会把未选的其他历史答案混入上下文。
- 客户端已取消同题多答入口；主进程拒绝每轮请求多个模型。已有多模型历史回答及分支保留，可选定一条历史答案后用单模型继续。
- 历史在左侧会话栏展示，支持按标题搜索与收起；窄窗口使用可收起的侧栏。首页以居中欢迎语、模型图标栏和输入框为重点，开始聊天后输入框固定在下方。草稿、模型选择与正在生成的页面由独立 UI 模块维护，后台状态刷新不会重建输入框。
- 普通 Enter 发送，Shift+Enter 换行，中文输入法确认键不发送。中断可停止；失败后由用户明确重新生成。

## 服务与兼容性

复用 `/api/dialogue`，通过主进程受限命令访问当前账号、当前盒子的 `applicationConnection('centaurai.wanx.dialogue', {backendProductId:'wanx'})`。界面不持有 Provider Key、盒子凭证或自定义请求地址。没有增加客户端预算、充值或支付开关。

切换模型后的首条消息使用现有 `POST /api/dialogue/sessions`。同一模型的后续消息仍用 `POST /sessions/{session_id}/answers/{answer_id}/continue`，不发送可选的 `models` 字段。客户端不再依赖 `capabilities.model_switch`，也不显示为跨模型沿用上下文而升级盒子的提示。本次仅调整客户端，不修改或部署后端。

账号、盒子或连接变化会中断本机旧 HTTP/SSE，并清空旧会话画面与草稿。切换 Tab 只停止前端订阅，不自动重发或停止服务器上的任务。断线后仅重新读取结果；发送结果未知时保留请求编号，用户确认时复用原编号。

## 验证

专项覆盖切换模型新建会话、同模型续聊、原历史和草稿保留、无能力标记的旧盒子兼容、旧流与历史响应隔离、重复请求、跨账号和盒子隔离、SSE 分片、消息转义、小窗口布局及输入法。原生 Electron 界面测试使用明确的合成回答，不能替代真实模型调用验收。

测试入口：`tests/unit/dialogue/test_dialogue.py`、`tests/integration/test_dialogue_api.py`、`wanx-client/tests/ai-dialogue*.test.mjs`。设置 `WANX_TEST_ELECTRON=1` 运行原生界面测试。

## 半人马视觉统一（第三张布局 + 第二张背景）

用户最终选择第三张的品牌欢迎页布局，背景采用第二张的暖白纸张材质。首页居中展示官方半人马标志、宋体欢迎语、模型胶囊栏及圆角输入区；历史默认收起，通过左上角入口打开，支持标题搜索和独立滚动。模型组居中。开始聊天后保留滚动消息与底部输入区。

纸纹为独立打包素材 `assets/materials/centaur-paper-v1.png`，不是整页截图；所有文字、按钮和输入均由实际 DOM 渲染。官方标志沿用 `assets/centaurai-mark.png`。控件图标复用 Ant Design 图标，并保留来源和 MIT 许可。

该视觉变更不改变计量、会话归属或数据结构。默认仍仅显示云端模型，切换模型的会话行为按上述最新使用方式执行，已移除的开场推荐不会恢复。本机客户端为本地验证构建，不替代跨系统安装验收。

## AI 对话模型显示配置

进入「个人头像 → 设置 → AI 对话模型 → 配置模型」，勾选要在对话页显示的可用云端模型，至少保留一款后保存。默认显示全部可用云端模型；恢复默认并保存后，新出现的可用云端模型也会自动纳入。自定义选择只显示明确勾选的模型。

偏好按万象账号、客户端身份和盒子身份分别保存在本机安全存储中，不随网关临时端口变化而丢失。保存后模型栏立即更新；账号、盒子切换及异步请求使用现有上下文校验。未保存的勾选不会被状态轮询覆盖；保存失败不宣称成功。

关闭显示不删除模型、不清理聊天记录、不停止已运行回答，也不修改盒端配置或发起模型请求。本次只覆盖现有云端模型；Codex、Claude ACP 不在本次接入范围。

## 取消同题多答

AI 对话每轮只能选一个模型，点击另一个模型会开启新对话并保留草稿。前端不再显示比较模式、返回单聊或多个模型分别回答文案；主进程同时限制发送请求只能携带一个模型，避免仅隐藏按钮。既有聊天、多模型历史和模型显示偏好均保留，不清理盒端数据。
