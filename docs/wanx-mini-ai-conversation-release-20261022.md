# WANX Mini：AI 对话与模型显示配置

日期：2026-10-22。分支：`AI-conversation`。基础源码：CodeUp `master` 的 `39771ba4de4b2182a69dcc9d68e68a0f815543cc`。

## 解决的问题

个人版可在客户端直接进行 AI 对话，不需要启动独立众见窗口。用户可自行选择显示哪些现有云端模型。旧盒子没有跨模型上下文切换能力时，之前会提示升级并阻止切换；现在切换到不同模型直接开启新对话，无需新增或升级盒端接口。

## 最终行为

- 标准导航为「应用 / AI对话 / 空间 / 盒子」。积分仍可从个人菜单与个人资料页访问。众见的应用页及托盘打开入口统一进入 AI 对话 Tab；AI 浏览器继续作为独立应用。
- 每轮只使用一个模型，取消同题多答。历史多答案和分支不删除；模型署名、复制、停止、重新生成与历史搜索继续可用。
- 点击不同模型，立即显示新对话页，保留尚未发送的草稿。不会携带原会话 ID 或父回答；直到用户发送才调用创建会话接口。点击当前模型不会清空对话。
- 使用同一模型继续聊时，沿用当前会话与所选回答的祖先上下文。原对话保留在当前账号、当前盒子的历史中。切换模型不会自动停止、重试或重新发送旧任务；旧任务结果可在原历史中读取。
- 默认不展示本地模型。模型组居中，使用半人马品牌标志、暖纸纹理、宋体欢迎语与紧凑输入区，支持小窗口、历史栏收起及中文输入法。

## 模型显示配置

入口：「个人头像 → 设置 → AI 对话模型 → 配置模型」。勾选可用云端模型，至少保留一款后保存。默认显示全部可用云端模型；「恢复默认」并保存后也会自动纳入后续新增的可用云端模型。

自定义选择按万象账号、客户端身份和盒子身份分别保存在本机系统加密存储中，不会因网关临时端口变化而丢失。关闭显示不删除后台模型、不清理历史、不发起模型请求，也不改变其他应用的模型配置。本次不接入 Codex / Claude ACP。

## 接口与数据边界

复用当前账号与当前盒子的受信连接及既有 `/api/dialogue` 接口。新模型首条消息调用 `POST /api/dialogue/sessions`；同模型续聊调用原 `continue` 接口且不传可选的 `models` 字段，不依赖 `capabilities.model_switch`。盒子仍需具备原有 AI 对话接口与可用模型服务。

凭据和 Provider Key 留在主进程及服务端，渲染进程仅使用固定 IPC 命令。账号或盒子切换会拒绝旧作用域的迟到结果；断线只恢复读取，发送结果未知时复用原请求编号确认。恢复连接不自动重复计费调用。

本次提交不修改后端、数据库、预算或支付逻辑，不部署远程盒子，不包含通知中心的独立改动。已有安装包、原始对话和账户数据保留；仓库中不包含真实账户凭据、聊天内容、本机加密偏好或运行数据。

新增素材均位于 `wanx-client/local-ui/renderer/assets/`，会随现有 `local-ui/**` 打包规则进入客户端：

不依赖生成工具临时目录或在线图片地址。
