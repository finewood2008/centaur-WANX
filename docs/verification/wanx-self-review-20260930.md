# 万象个人本体：点位与校准工作区

## 设计与实现

- 参考旧版个人本体的信任环与本人校准语义；不迁入旧产品的六分区或个人数据。
- 万象现有记忆、情绪与待沉淀内容形成外侧线索，经过提炼与本人核对后成为理解，再由本人五级校准决定距离。
- 全景展示来源窗口内全部点位，不再按 80 点切页；列表保留分页。来源窗口每类 500 条，超出时继续显示覆盖提示。
- 点选、原文、描述调整、情境限定、校准与对话合为同一个工作区；确认后继续校准，点位角度不因内容版本变化而改变。
- 单点对话服务端绑定目标及版本，仅发送当前点的材料和该点有效对话；不接受其他目标的修改建议。全局理解保留独立入口。
- 情境与理想方向不进入代表长期本体的内圈。系统置信度不参与本人贴合程度。
- 标题及提示文案使用万象；原始资料与用户给专家起的名字不作为产品品牌替换对象。

## 验证

- 前端合成测试：全景超过 80 个点；确认后原地校准；点位对话版本绑定；切点草稿隔离；过期建议禁止采用；情境/理想方向不进入中心。
- 后端合成测试：选中目标限定输入材料和历史；旧版本、未知目标、越界模型引用被拒绝；对话不自动确认。
- OpenAPI 请求的 target_id / target_version 和响应字段已检查，均有类型及字段说明。
- 本次不调用真实个人资料进行模型批量提炼或代替用户确认。模型语义效果不以合成测试替代。
- 本机升级前备份：`~/.octop/backups/before-wanx-review-workspace-20260930-102856`，包含主库、运行包和桌面应用。
