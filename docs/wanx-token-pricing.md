# WANX Token 积分：用量记录与试算

2026-10-15 产品决定：取消任务预算、追加预算、自动任务单次/每日积分授权，以及会暂停模型调用的中央预算网关。普通对话不再先报价、申请额度或等待追加确认，应用恢复使用已有的模型服务配置。本地模型与云端模型的原有选择不变。

当前保留账号统一余额、历史流水和非阻断的任务用量记录。知君按一轮、半人马环按一次执行、众见按同次并行回答、超级参谋团按父任务归集用量。统计故障不会阻断正常调用；账号关联失败时只记录未关联用量，不猜测账号。真实支付、自动发放和真实扣费继续关闭，历史用量不补扣。

任务记录不再输出上限、超限检查或报价有效期；预计点数根据实际已核实用量计算，不再截断到旧上限。未知价格和用量仍明确待核对，内部保留成本信息，用户侧不展示采购价格和利润。

## 单位和费率

1 元 = 1,000 积分；1 积分对应 0.0003 元可计费模型成本。使用整数纳元（1 元 = 10^9 纳元）存成本，一点对应 300,000 纳元。推理 Token 不额外叠加输出费用。

价格快照当前覆盖 DeepSeek Flash / V4 Pro 及已登记别名，区分缓存读取、非缓存输入、输出和峰谷时段。仅对官方 `api.deepseek.com` 的调用使用此价卡；相同模型名称出现在其他供应商时不会冒用官方采购价。缺少核实的节假日日历时，工作日高峰价格标为 provisional。未配置缓存写入价格的模型若报告缓存写入则待核对，不能当作零成本。

[DeepSeek 官方价目](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 是快照依据，实际采购仍需供应商账单核对。现有价卡不是实时抓取价目，也不等于已核对的供应商账单。

## 现行接口

- `GET /api/credits/account/balance`、`transactions`、`reservations/{id}`：账号余额和历史流水详情。
- `GET /api/credits/account/meter-session?application_id=…`：仅作账号与用量的安全关联，不是预算授权。
- `GET /api/credits/account/tasks`、`tasks/{id}`：账号隔离的任务用量。
- 管理员 `token-pricing`、`token-pricing/preview`、`token-report`、`lots/{id}/order-metadata`：价卡、套餐测算、内部成本与订单归属；不自动发点或扣费。

已移除报价、任务授权/追加、自动任务预算和调度凭证安装接口。旧预算网关进程、客户端配置与 SDK 强制路由不再使用。029/030 数据库迁移及历史记录保留，避免破坏已有数据库；这些历史字段不代表功能仍启用。
